# Exorus

Кроссплатформенный стриминговый сервис музыки с рекомендательной системой на основе машинного обучения и совместным прослушиванием.

> Дипломный проект. Статус: проектирование.

## Возможности

- **Стриминг музыки:** каталог, поиск, плейлисты, адаптивное воспроизведение (HLS).
- **ML-рекомендации:** гибридная модель на аудио-эмбеддингах и истории прослушиваний.
- **Совместное прослушивание:** синхронное воспроизведение на 2–3 устройствах, управляет хозяин комнаты.
- **Мессенджер:** чат в комнате прослушивания и личные сообщения.
- **Платформы:** веб-версия (ПК и телефон, PWA) и десктопное приложение для Windows.

## Источники музыки

- [Jamendo](https://developer.jamendo.com/v3.0) — полные треки под лицензиями Creative Commons.
- [Deezer API](https://developers.deezer.com/api) — чарты, новинки, метаданные, 30-секундные превью.
